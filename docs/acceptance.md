# Приёмочная проверка

Выполнить на Windows с установленными Node, LibreOffice и браузером.
1. npm.cmd ci; python -m unittest discover -s tests -v.
2. python generate_slides.py --plan examples/lesson.md --output out --pdf.
3. Открыть PPTX и PDF, сравнить число слайдов с входом.
4. Изменить текст PPTX, сохранить отдельную копию, открыть её и проверить изменение.
5. Повторить генерацию и проверить generated/regenerated в JSONL.
6. Проверить расширенный пример и читаемость кода/кириллицы.
7. Записать фактические версии программ, дату и результат каждого пункта.

Статус реальной приёмки этой переработанной версии: заполнить после запуска.
Автоматические тесты используют имитацию Marp и не доказывают редактируемость PPTX.
