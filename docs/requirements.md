# Требования и приёмка

1. Заголовки и разделители задают слайды; тезисы, ссылки и код сохраняются.
2. Marp создаёт PPTX с редактируемым текстом; экспорт зависит от LibreOffice.
3. Параметр --pdf дополнительно создаёт PDF.
4. Неполные места обозначаются видимыми TODO для ручной доработки.
5. Метаданные связывают план с результатами; JSONL хранит события generated/regenerated.
6. Ошибка экспорта не заменяет ранее готовые PPTX/PDF и не записывает успех.
7. Проверки: unittest с имитацией Marp; отдельно ручная приёмка настоящего экспорта.
Экономия времени — гипотеза. Процент экономии не заявляется без сравнительного измерения.
