# Пользовательские сценарии

## Создать презентацию
Преподаватель готовит examples/lesson.md и запускает генератор с --pdf.
Он открывает out/lesson.pptx, проверяет заголовки, редактирует тезис и сохраняет
отдельную копию lesson-edited.pptx. PDF используется для просмотра.

## Обновить занятие
Автор меняет исходный Markdown и повторяет запуск. Генератор заменяет черновик
и экспорты, записывает regenerated. Ручные правки в старом PPTX автоматически
не переносятся; исходником для повторной генерации служит Markdown.

## Разобраться с ошибкой
При ошибке автор читает сообщение CLI, проверяет путь, зависимости и разметку.
Ранее созданные PPTX/PDF сохраняются при сбое конвертации. Подробности в reliability.md.
