# Формат входа

Используйте ATX-заголовки #–###### и разделители --- вне блоков кода.
Каждый заголовок начинает новый слайд. Ограждения ``` и ~~~ защищают код от разбора.
Входной YAML front matter не поддерживается. Нужен хотя бы один заголовок.
