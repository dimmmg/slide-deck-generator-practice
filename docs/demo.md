3. Открыть PPTX, изменить тезис и сохранить отдельную копию. Открыть PDF.
4. Изменить Markdown и повторить команду. Показать событие regenerated.
5. Объяснить архитектуру и ограничения: TODO требуют проверки, ручные правки PPTX
   не переносятся, журнал локальный, редактируемый экспорт зависит от LibreOffice.
6. Показать тесты, историю PR и итоговый тег. Ответить на вопросы.
