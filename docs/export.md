# Экспорт

`python generate_slides.py --plan examples/lesson.md --output out --pdf`
создаёт PPTX и PDF. Без --pdf создаётся только PPTX; --markdown-only сохраняет
лишь черновик и не запускает Marp. Ошибки возвращают код 1, ошибки аргументов — 2.
Сигнатуры ZIP/PDF проверяют базовый формат, но не доказывают визуальное качество.
Ручная проверка обязательна для редактируемости, числа слайдов и переполнения текста.
Ссылки сохраняются как Markdown; загрузка локальных ресурсов Marp специально не разрешается.
