# Материалы для отчёта по практике

Автор: Горбовский Дмитрий Олегович. Группа 14321-ДБ, 3 курс. Индивидуальный проект.

Проблема: ручное перенесение плана занятия в слайды требует повторного ввода
и затрудняет синхронизацию текста. Генератор создаёт черновик из Markdown,
сохраняет ссылки и тезисы и обозначает места для ручной доработки.

Результат системы: локальные редактируемый PPTX, PDF, Markdown, метаданные и журнал.
Архитектура — docs/architecture.md. Сценарии — docs/use-cases.md.
Автоматические проверки — tests/test_generator.py; ручная приёмка — docs/acceptance.md.

Для итогового отчёта добавить фактические результаты запуска, читаемую диаграмму,
снимки изменённого PPTX и ссылки на реальные Issue, PR, коммиты и модули.
Ежедневная запись: План → Отчёт о выполненном → Итог для пользователя → Ссылки.
Не считать план или подготовленные файлы свидетельством выполнения в указанный день.
Не заявлять измеренную экономию времени без сравнительного эксперимента.
